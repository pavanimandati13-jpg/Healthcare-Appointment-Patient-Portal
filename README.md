## 📌 Project Description

The **Healthcare Appointment & Patient Portal** is a responsive web application that allows users to register patient details and create an appointment.

The portal includes a patient registration form, appointment details table, and health information section as required in the project specification.

---

## 🎯 Objectives

The main objectives of this project are:

* Register patient information.
* Collect appointment details.
* Select a healthcare department.
* Select a doctor.
* Schedule an appointment date and time.
* Display appointment information.
* Display patient health information.
* Provide a responsive and user-friendly interface.

---

## ✨ Features

### 👤 Patient Registration

The registration form includes:

* Patient Name
* Email
* Mobile Number
* Date of Birth
* Gender
* Blood Group
* Department
* Doctor Selection
* Appointment Date
* Appointment Time
* Address
* Symptoms / Health Concern

The form also provides **HTML5 validation** and **Register** and **Reset** buttons.

### 📅 Appointment Section

The appointment table displays:

* Appointment ID
* Patient Name
* Department
* Doctor
* Date
* Time
* Appointment Status

### 📋 Health Information

The portal displays:

* Patient Name
* Blood Group
* Department
* Doctor
* Appointment Date
* Appointment Time
* Symptoms
* Appointment Status
